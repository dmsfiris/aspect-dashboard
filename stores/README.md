# Stores Folder

This folder contains PHP files related to managing stores within the Aspect Dashboard application.

## Files

- `manage-stores.php`  
  The PHP script responsible for the store management interface, including listing, adding, editing, or deleting stores via interaction with the backend API or data source.

## Notes

- Store data management is handled through the API server and JSON files located elsewhere (`node-api/stores/stores.json`).
- Ensure `manage-stores.php` is kept updated to match the API endpoints and data format.
- Use this folder for PHP scripts and resources strictly related to store management UI and server-side logic.
