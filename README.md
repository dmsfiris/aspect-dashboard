# Aspect Dashboard

A PHP-based user dashboard for managing stores, domains, and platform activity — part of the open-source **AspectSoft** project collection.

## Features

- Comprehensive store management overview  
- Domain management with API integration  
- Responsive, modern, and clean design  
- Simple session-based authentication  

## Requirements

- PHP 7.4 or higher  
- A web server such as Apache or Nginx  
- Write permissions for data files (e.g., JSON storage files)  

## Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/dmsfiris/aspect-dashboard.git
   ```
   
2. **Place the project files** in your web server’s root directory.

3. **Access the dashboard** through your browser, for example:
   
   http://localhost/aspect-dashboard/
   
## Usage Notes

- Data is stored in JSON files for simplicity and portability.  
- API endpoints run on a Node.js server (default port 5000) — ensure this server is running for full functionality.  
- Domains can be added without assigning them to a store initially.
